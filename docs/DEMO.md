# NoteHack Demo

演示账号用于检查排版、编辑器、组织、分享与打印体验。当前状态：10 篇活跃笔记 + 1 篇回收站笔记，3 个空间，1 份备份。

- 登录邮箱：`demo@notehack.com`
- 显示名：`demonotehack.com`
- 密码与演示分享链接：见服务器 `/root/notehack-demo-credentials.txt`（0600，不提交到仓库）
- 当前演示空间：`演示空间`（个人）、`产品团队`（团队）、`阅读与写作`（个人）

演示数据覆盖：

- 个人空间「演示空间」：工作/项目/会议/学习/读书/旅行文件夹
- 第二个个人空间「阅读与写作」
- 团队空间「产品团队」及其文件夹与成员角色入口
- 中文笔记、英文笔记、Markdown 语法、GFM 表格、任务列表、引用、代码
- 「知识地图」包含 5 个真实可点击的 `[[...]]` 双向链接，目标覆盖工作、阅读、旅行
- 图片附件、文本附件、表格与文档排版
- 标签、收藏、置顶、最近编辑、回收站
- 评论、版本历史；「知识地图」历史中含一条 `reason='conflict'` 的冲突快照（不进入笔记列表）
- 公开分享（只读、评论、密码保护）
- A4 打印样式与 PDF 字号；分享页打印时间完整、更新时间相对
- 一份空间备份

密码和分享链接只放在服务器凭据文件中，不进入 Git。


## 快速检查

1. 登录 demo，确认侧栏空间为「演示空间」，可切换到「产品团队」与「阅读与写作」。
2. 打开「知识地图」，点击任意蓝色链接标题，应直接跳转到对应笔记。
3. 打开右侧“历史”，应看到“冲突副本”，且笔记列表中没有冲突副本。
4. 打开「Markdown 语法与排版演示」，输入 `/` 插入表格，确认表格保存后仍是 Markdown。
5. 打开任意笔记 → 更多 → 分享，复制分享链接；公开页可切换只读/评论/密码。
6. 打印分享页：发布/打印时间为完整日期时间，更新时间为相对时间。
7. 移动端 390px：侧栏无阴影、菜单按钮在搜索左侧、底部四项、空间可切换、只有“…”打开退出菜单。
